# ✦ Cosmo Downloader v1.9

A blazing-fast, modern download manager for Windows with seamless browser integration.

## Installation

1. Run **`CosmoDownloader-Setup-v1.9.exe`** to install Cosmo Downloader on your system.
2. The installer will automatically configure the application, register browser bridges, and create desktop shortcuts.

---

## Browser Extension Setup

Open the **`Browser-Extensions`** folder:

### Google Chrome / Brave / Microsoft Edge / Opera
1. Open your browser's extensions page:
   - **Chrome**: `chrome://extensions`
   - **Brave**: `brave://extensions`
   - **Edge**: `edge://extensions`
   - **Opera**: `opera://extensions`
2. Enable **Developer mode** (toggle in the top-right corner).
3. Extract `CosmoDownloader-Chrome-Edge-Brave.zip` and click **Load unpacked**, then select the extracted folder.

### Mozilla Firefox
1. Open Firefox and go to `about:addons`.
2. Click the gear icon ⚙ (top-right) and select **Install Add-on From File...**.
3. Select `CosmoDownloader-Firefox.xpi` (or `CosmoDownloader-Firefox.zip`).

## Key Features

- **Blazing Speed**: Adaptive multi-segment downloading for maximum network utilization.
- **Instant Browser Interception**: Automatically catches downloads from YouTube, video streaming sites, and all file links.
- **Topmost "Download File Info" Dialog**: Clean IDM-style prompt with category detection, remember-path options, and file size detection even when the main app is closed.
- **Persistent Background Integration**: Seamless native messaging bridge keeps catching downloads even when the main window is closed.
- **Cosmic Dark Theme**: Built with modern Windows 11 fluent aesthetics.
